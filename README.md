# AI Resume Screener

An AI-powered resume screening web application built 
with Flask and Sentence Transformers.

## What it does
- Upload multiple PDF resumes
- Paste a job description
- AI reads and scores each resume
- Returns ranked list of candidates by match score

## Tech Stack
- Python
- Flask
- Sentence Transformers
- PyMuPDF (PDF reading)
- HTML/CSS

## How to Run
1. Clone the repository
2. Create virtual environment: `py -3.11 -m venv venv`
3. Activate: `venv\Scripts\activate`
4. Install: `pip install flask transformers sentence-transformers pymupdf torch`
5. Run: `python app.py`
6. Open: `http://127.0.0.1:5000`
